# 来源证明与迁移登记

本目录记录治理材料、公开依赖文档、黄金夹具和获准自有非画布切片的来源、审核人、审核时间、版本与哈希。

## 后续计划

1. 为每项输入材料和每个接受迁移文件建立唯一记录。
2. 记录获取位置、摘要、源/目标哈希、依赖闭包和审核结论。
3. 发生变更时重新审核并保留版本关系。
4. 对共享依赖、画布直接依赖和归属不明代码保留隔离结论。
5. 当前修复实施核验见 `attestations/reviews/CLEANROOM-REMEDIATION-VERIFICATION-2026-09-17.md`；该记录不等同于独立发布授权。

## 门禁

没有来源记录和审核结论的材料，视为不可用输入；来源证明不得包含旧仓库源码、用户数据或凭据。用户授权不等于架构解耦，迁移仍须通过依赖闭包检查。
