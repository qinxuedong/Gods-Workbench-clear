结论
================================================================
1. 真实 Linux（Ubuntu 24.04.4 / glibc / CPython 3.11.15）按 requirements-dev.txt 安装成功，63 passed。
2. Linux 闭包相对 Windows 主表：多 uvloop==0.22.1，少 colorama（Windows 专有），其余 29 条版本一致。
3. 因此 requirements.lock.hashes 的 Windows 段不可直接用于 Linux：
   - 需并入 uvloop（含上列 sha256）；
   - 需允许 colorama 在 Linux 缺失。
4. 该证据为本地 Linux（WSL2）实测，不等于生产容器验收，也不等于远端 CI（远端 CI 为 GitHub ubuntu-latest，已另有 run 证据）。
