# Phase 12｜分享、CLI、媒体缓存方案独立审核

对象：SHARE-CLOSURE-DESIGN、CLI-CLOSURE-DESIGN、MEDIA-CACHE-DESIGN。本轮仅审核方案，不声称实现验收。未调用真实登录、退出、余额或付费服务。

## 快速结论

- **分享：有条件通过**。同事务重验票据/归属、真实读回、独立限流计数和受限媒体路由方向正确；下列S1–S3纳入Required后可实施。
- **CLI：修订后通过**。C1为方案正文必须修改的语义错误，其余C2–C3为实现门禁；不需新建访客/账号体系。
- **媒体缓存：有条件通过**。专用分镜目录、精确ID匹配、保留不明归属旧帧正确；M1–M2纳入Required后可实施。

## 分享 Required

**S1｜令牌关联和限流资源边界。**评论/审批读回严格按share_id+asset_id隔离，旧记录不可仅按asset_id猜测归属；显式session_id的素材匹配在写入时仍重验。错误口令计数须提交，未知token不得建立无上限持久桶；桶数量/过期清理/请求体长度需有限额。计数失败按失败关闭处理，不能继续接受写入。受控测试覆盖票据轮换、分享到期和写入的竞争顺序，不能先检查后在锁外落盘。

**S2｜公共媒体不可变成同源主动内容执行入口。**路径准入不等于文件安全。真实媒体端点只inline明确准入的图片/音视频类型；HTML、SVG等主动内容及不确定类型必须拒绝或attachment+安全类型，nosniff不是唯一保护。can_download=false并非DRM的边界保留。GET/Range/错误响应都不应缓存票据授权结果；不存在/跨分享资产不能通过FileResponse文件存在性泄露额外内容。下载URL参数用URL/URLSearchParams，不再拼接&。

**S3｜票据/Blob生命周期。**再次access会使旧票据失效必须在UI明确，不能宣称多访客独立会话已实现。换分享、票据更换、离页立即失效旧请求代次并Abort，防止迟到响应重建已撤销URL；终态及失败释放已有URL。Blob预览设置可核验的大小上限/异常分支，不能把任意大小本地视频全部读进浏览器内存。401/410后不能继续使用陈旧媒体或旧票据发写请求。

## CLI Required

**C1｜非零login退出不能推导logged_in=false。**失败的登录尝试不能证明本机之前的凭据已经消失。请将方案第4点“非零false”改为“操作失败；logged_in=null/result_unknown或明确last_operation_failed”。只有已验证语义的成功logout可以记录false；成功普通login记录true仍必须标明last_operation、observed_at，不能升级为持续在线/实时登录态。重启unknown保持。

**C2｜控制器代次、授权材料与进程回收。**每次进程有独立执行代次；旧读线程/超时回调不得覆盖后续操作状态。锁不能跨阻塞read/join等待；所有终态、超时、退出和logout清除verification_uri/user_code，任何主体查询都不能读到上一次材料。异主体保护覆盖start和status而不只是启动接口。输出流限制按实际读取字节计，不能等readline读到换行后才检查64KiB。5分钟超时要能主动打断未换行/未关闭stdout的子进程并回收；只回收本控制器所有的进程，不杀同名无关进程。

**C3｜外部协议与UI证据分层。**固定可执行/argv、治理权限、稳定主体归属必须同时检查；授权URI字段可解析且来源明确，禁止把输出任意URL当授权链接。若要扩大接受host/query格式，先由官方帮助/协议或配置明确准入，不自动放宽。输出夹具必须包括无换行超量、启动即退出、失败前已有成功观测、异主体status、终态后材料清除和旧线程迟到。HTTP200启动仅代表接管进程；不得以假CLI验收声称真实Dreamina账户已登录。Windows后台进程不弹出额外控制台。

## 媒体缓存 Required

**M1｜先验证原始对象，再操作解析后的路径。**只做resolve后within-root判断仍不足以排除“指向另一资产目录的内部符号链接”。资产目录及文件都须拒绝符号链接/重解析别名（以实际平台能力覆盖），检查真实普通文件，固定专用缓存根；校验失败不删除任何文件。精确匹配规则须与生成命名共用，不能只把startswith换成另一个宽泛glob。fixture包含asset_1/asset_10、同资产单帧、clip和目录内外链接。

**M2｜陈旧缓存和失败响应真实。**旧混用布局不删除且显式报告保留，不将“新专用目录清零”写成全部历史缓存清零。下载路径也必须从专用目录映射，生成→HTTP下载hash→删除→HTTP404真实串联。部分文件拒绝/失败时removed仅统计已删除文件，并报告失败，不能返回整批完成。匿名同名跨根缓存覆盖尚未解决的范围继续保留，不因精确删除修复而宣称其已解决。

## 双轴判定

规范轴：上述限制落实后与洁净室、无新增二进制、固定路径/权限、真实副作用原则相容。需求轴：能补分享读回/期限/限流与媒体下载、CLI状态观察以及真实分镜删除缺口；但不包括公网托管、多worker登录控制、跨阅读器/DRM保证或旧缓存来源推断。实现完成后仍需独立测试，方案结论不能代替实现通过。
