# 产物路径与内部状态隔离｜独立方案审核

**结论：P1方向正确，方案有条件通过，应优先修复；不是实现验收。**按受控复现，读取内部状态与删除内部状态均突破产物边界；不能通过禁用单个文件名补丁解决。

最小Required：

1. **命名空间是准入边界，不是任意data_root下文件。**固定四个允许目录，不允许前缀相似名、绝对路径、`..`、Windows盘符/UNC/ADS绕过。先验证输入路径归属，再验证真实文件；不存在但命名空间合法才可skip，不存在的未知目录仍403。不以.json/.db后缀单独决定是否合法：允许目录内合法用户附件与根内部状态应按归属区别。
2. **链接检查覆盖所有原始路径组件。**仅对最终文件is_symlink或resolve后relative_to还不够：四个目录自身、其下父目录、最终文件中的符号链接/Junction/重解析别名均需拒绝，且resolve后仍在配置数据根内的同一个真实准入目录。不得把攻击者可改的符号链接目标重新定义为白名单根。Windows需实际Junction夹具，不把不支持的夹具跳过称为通过。
3. **所有旁路使用同一准入函数。**path和asset_id推导的候选、storage-files列表和删除、下载响应前最后检查一致；受限视频目录明确拒绝。列表不能先递归跟随链接再仅过滤返回项；不应读取内部文件内容/秘密元数据。
4. **批量预检与执行边界真实。**先完整校验所有输入，再执行删除；混合非法请求不产生任何删除。预检通过后若发生磁盘I/O失败，须准确返回部分失败，不能承诺文件系统事务回滚。操作前重新检查目标类型/边界以降低竞态，不跟随已被换成链接的对象。
5. **回归矩阵**：匿名401、readonly读取内部状态403、editor删除内部状态403、readonly删除合法产物403；合法四目录下载字节hash/删除后GET；前缀相似目录、嵌套链接/Junction、绝对/ADS/路径穿越、asset_id候选旁路、混合批量与video目录拒绝。错误不泄漏原始绝对路径或内部内容。

本补丁隔离内部状态，不自动解决同一合法产物目录内的所有租户/项目ACL问题；视频仍走专用鉴权。无需读取或删除真实团队数据库做验证，全部使用临时目录标记文件。
